# Creates R6 object for DateRange

Creates R6 object for DateRange

## Usage

``` r
createDateRange(startDate, endDate)
```

## Arguments

- startDate:

  a character vector representing a date in YYYY-MM-DD format

- endDate:

  a character vector representing a date in YYYY-MM-DD format

## Value

A `DateRange` R6 object containing the start and end date strings in
`YYYY-MM-DD` format.
